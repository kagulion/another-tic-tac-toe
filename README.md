# Another Tic-Tac-Toe

A simple, clean, and functional Tic-Tac-Toe game built with HTML, CSS, and Vanilla JavaScript.

## Features

- **Classic Gameplay:** Play the traditional 3x3 Tic-Tac-Toe game.
- **Score Tracking:** Keeps track of wins for both Player X and Player O during the session.
- **Win Detection:** Automatically detects when a player wins and highlights the winning combination in red.
- **Draw Detection:** Detects when the board is full and the game ends in a tie.
- **Reset Functionality:** Easily start a new game while maintaining the current scores.
- **Responsive Design:** Clean and centered UI using CSS Grid and Flexbox.
